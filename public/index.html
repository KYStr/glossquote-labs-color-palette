Gloss Tools / 配色

配色與文字對比

手動整理顏色、提交有效色碼，再比較文字色與背景色的對比。

互動功能需要 JavaScript

啟用 JavaScript 後才能編輯顏色、計算對比、複製或下載 CSS。資料不會自動保存。

使用方式與範圍

手動整理 2 至 8 個不透明 sRGB 顏色，使用 HEX、RGB 或 HSL 編輯；選擇文字色與背景色後查看 WCAG 對比比值。所有計算都在這個頁面的記憶體中完成。

不需要帳號。頁面載入後，色彩計算都在本機完成。工具不會把色彩寫入儲存空間、網址或伺服器。重整、重設或切換語言會清除本頁的草稿和色票；下載檔案由你自行保存。重設不會清除已複製到作業系統的文字。

常見問題

通過對比檢查就代表網站無障礙嗎？

不代表。結果只說明這兩個不透明色彩是否達到所列文字對比門檻；字級、焦點、鍵盤操作及其他頁面內容仍要另外檢查。

支援透明色或漸層嗎？

目前只支援不透明 sRGB。透明與漸層會受背景和位置影響，這個版本不計算它們。

為什麼 HSL 換回去有微小差異？

工具以 8-bit RGB 保存顏色。HSL 輸入會在提交時轉成整數 RGB，因此中間數值不一定完全可逆。

色票會保存嗎？

不會。重整、重設或切換語言後會回到新頁面的起始色票。需要保留時，請自行複製色碼或下載 CSS。

可以從照片擷取配色嗎？

不可以。第一版只提供手動選色，不讀取圖片。
