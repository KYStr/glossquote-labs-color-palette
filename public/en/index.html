Gloss Tools / Color palette

Color palette and text contrast

Arrange colors by hand, edit committed values, and compare text and background contrast.

JavaScript is required for interactive features

Enable JavaScript to edit colors, calculate contrast, copy a value, or download CSS. Nothing is saved automatically.

How to use this tool

Manually arrange 2 to 8 opaque sRGB colors in HEX, RGB, or HSL. Choose a text and background color to check their WCAG contrast ratio. Calculations run in this page's memory.

No account is needed. After the page loads, color calculations run locally. The tool does not write colors to storage, the URL, or a server. Refreshing, resetting, or changing languages clears this page's drafts and palette; save downloads yourself. Reset cannot clear text already copied to the operating system clipboard.

Frequently asked questions

Does passing the contrast check make my website accessible?

No. It only reports whether these two opaque colors meet the listed text contrast thresholds. Type size, focus, keyboard use, and other page content still need separate review.

Does the tool support transparency or gradients?

It supports opaque sRGB only. Transparency and gradients depend on background and position, so this version does not calculate them.

Why can HSL convert back with a small difference?

Colors are stored as 8-bit RGB. HSL input becomes integer RGB when committed, so intermediate values are not always reversible.

Will my palette be saved?

No. Refreshing, resetting, or changing languages starts a fresh page. Copy color codes or download CSS if you need to keep them.

Can I extract colors from a photo?

No. The first version is for manual color selection and does not read images.
